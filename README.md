## Sobre mim

Construo servicos de backend e camadas de dados com **Python e FastAPI**, e as interfaces **Vue.js** que ficam por cima deles. Modelo dados relacionais em **PostgreSQL** e dados conectados em **Neo4j**.

- Interesse em arquitetura, modelagem de dados, grafos, automacao, APIs, IA aplicada e processamento de dados
- No laboratorio agora: **Bun, Elysia e TypeScript**
- Aberto a conversar sobre backend, dados e grafos
